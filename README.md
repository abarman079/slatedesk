# SlateDesk

SlateDesk is a role-based Assignment and Submission Management System for schools and colleges.

## Project status

The project is currently under active development.

## User roles

- Admin
- Teacher
- Student

## Technology stack

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend

- ASP.NET Core Web API
- C#
- Entity Framework Core
- PostgreSQL

### Authentication

- JWT access tokens
- Refresh-token rotation
- Role-based authorization

### Testing

- xUnit
- Integration testing with WebApplicationFactory
